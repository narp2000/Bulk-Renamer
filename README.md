# Bulk Renamer

Renombra archivos en lote a partir de una lista `nombre actual → nombre nuevo`.

- **Web (Streamlit Cloud):** subes los archivos, pegas la lista y descargas un ZIP.
- **Local (`streamlit run app.py`):** además renombra directamente en una carpeta de tu PC, con opción de deshacer.

Validaciones portadas de [bulk-rename-core](https://github.com/adityasingh031901-star/bulk-rename-core) (MIT).

```bash
pip install -r requirements.txt
streamlit run app.py
```
